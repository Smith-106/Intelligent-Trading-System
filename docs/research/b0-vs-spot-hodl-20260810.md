## 3. 为什么会输 HODL？（机制，不是借口）

1. **趋势/门控策略大量时间空仓或降暴露** → 吃不到长斜坡 beta。  
2. **1547 笔交易成本**（+ funding 估计年化 ~4.8%）→ 已知 drag ~21pp（BTC reframe 零成本 vs 生产）。  
3. **评估窗含史诗级山寨牛** → SOL/等权 HODL 把基准抬到不公平的「神级 beta」。  
4. **主模式 shared RP 主动压风险** → 收益上限被设计砍掉换回撤。  
5. **btc_only 策略 −11.8%** 说明：问题不只是「组合稀释」，单标的主动交易在本窗也没打过 HODL。

## 4. 若目标是「比持币强」，系统缺什么？

当前北极星是 **paper-first 研究 OS**，不是 **beat-BTC fund**。若要转向后者，需要**新合同**（禁止静默改 B0/B3–B5 冻结），例如：

| 方向 | 说明 |
|------|------|
| Beta + overlay | 核心现货 beta + 小仓 overlay，benchmark=BTC |
| 多空/对冲后超额 | 报告 **alpha vs BTC**，而非绝对收益 |
| 熊市/高波动切片 | HODL 回撤 70%+ 时策略的 utility |
| 成本更低路径 | maker/少换手；否则难超 HODL |

**无新假设就不要开 W28「再调参打 HODL」。**
