# 产品裁决：若基准是「定持 BTC」，主动交易相对失败

**Date**: 2026-08-10  
**触发**: 用户判断 — 不能超越定持 BTC 则交易相对失败；BTC 牛熊清晰，2022→2025 现货易拿数倍。  
**结论**: **在「绝对收益 / 战胜持币」产品语义下，该判断成立。当前 B0 主路径相对失败。**

## 3. 两种「成功」必须拆开

| 定义 | B0 / 当前系统 | 用户「定持 BTC」标准 |
|------|---------------|----------------------|
| A. 研究 OS 可复现、成本门、风控管道 | ✅ 大体达成 | 不关心 |
| B. 绝对收益战胜 BTC HODL | ❌ **失败** | **唯一及格线** |
| C. 熊市少亏 / 回撤小 | ⚠️ 有（DD 小） | 次要；牛市少赚不可用「回撤」抵消 |
| D. live 可上 | ❌ 未完成（T023/T024） | 另论 |

**相对失败**指的是 **定义 B**。  
用定义 A 的 PAPER-GO 反驳定义 B，是 **换题**，不采纳。

## 4. 为什么「会交易」仍可能输给「会拿着」

1. **周期 beta 是主菜**：2022 底→2025 峰量级收益来自方向暴露，不是日频择时。  
2. **空仓/降仓 = 主动拒绝主菜**：趋势门控在牛市的机会成本极大。  
3. **换手税**：千笔级费滑 + funding，在已弱于 beta 的曲线上再抽一层。  
4. **多标的 RP 更不是「纯 BTC 周期账户」**：产品叙事若是 BTC 周期，基准就该是 **BTC**，不是组合波动率。  

在 2022 单年 HODL 也 −65%——「拿着很容易」**只在跨过熊、坐上牛**时成立；但用户比的是 **2022 拿到 2025 的跨周期结果**，那一刀 HODL 仍然轻易赢过当前 B0 全窗。

## 6. 若要坚持「交易必须赢 HODL」——该怎么走

**不要**: 调参刷 B0、开空 W28、把 risk_parity +227% 当战胜市场。  

**要**（新合同，独立 ID）:

1. **Benchmark 强制**: 每份报告 `strategy_ret − BTC_HODL`（同窗、同起始权益）。  
2. **结构**: 默认 **高 BTC beta + 小仓 overlay**（或期货对冲后的净 alpha），而非「经常空仓的中低频趋势」当主菜。  
3. **周期切片门**: 至少单独披露 `2022熊` / `2023–2025牛` / `全窗`；牛市大幅输 beta → **产品 NO-GO**（即使研究门过）。  
4. **成本后仍要赢**: 费滑+funding 后 excess vs BTC 才算。  
5. **Paper 仍要 T023/T024**: 赢回测但不赢 paper 样本仍是另一类失败。

无此假设与合同前：**承认相对失败，把精力放在基准重定义或 beta 产品，而不是美化 +5%。**
