# QuantFlow v0.7.0

发布日期：2026-08-11

## 亮点

**OSS 对抗 residual 改进波次 IMP-01…05** 落地：研究路径诚实晋级指纹、Path B 多窗 OOS 加厚、Feature Store PIT 审计、多标的 dual-path 报告、会话健康与告警 taxonomy。**不换引擎**；`promotion_eligible` 恒 false；禁止 `combined_score`。

### 研究 OS（IMP-01 / IMP-02）

- dual-path / path_b_oos 报告附着 **诚实** `execution_path=vectorized` + `data_fingerprint`
- 研究路径 **不** 伪称 `paper_replay` GO；`assert_promotion_path_ready` 仍拒绝 vectorized
- Path B 默认 **6-window** OOS + `cost_attachment`（fee_slip_grid + funding_tca assumption）
- 可选 `--compare-modes`（rolling↔anchored，无合并得分）

### 数据安全（IMP-03）

- `quantflow/data/pit_audit.py`：fail-closed 未来函数审计
- 复用并补强 `tests/unit/test_feature_store_pit.py` + `test_pit_audit.py`

### 多标的研究（IMP-04）

- `multi_symbol_dual_path`：≥2 OKX symbols 并列 Path A/B
- equal book 权重仅展示；**无** `combined_score`；非多所

### 运维可读性（IMP-05）

- Session health Prometheus gauges（up / bars / bar age / open orders）
- `build_session_health` + `alert_taxonomy_summary`
- 文档：`docs/ops/alert-taxonomy-session-health.md`

### 仓库清理（同版本）

- 取消跟踪 `.workflow/scratch/` 运行时日志与截图（~153 文件）
- 强化 `.gitignore`：`.workflow/tmp/`、`archive/`、`scratch/`、search-daemon 生成物
- 本地 `__pycache__` / pytest / ruff 缓存清理

## 破坏性变更

无默认交易行为破坏。研究报告新增字段为附加元数据。
