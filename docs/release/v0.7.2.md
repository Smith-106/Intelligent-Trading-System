# QuantFlow v0.7.2

发布日期：2026-08-12

## 亮点

**工程化 uplift wave-1 + L6 研究 GO 导出 + residual 门禁收口 patch。**  
不换引擎；不改 B0/B3–B5 冻结；`promotion_eligible` 恒 false；parity 仅 paper↔live。

### 工程化 uplift（ENG-UP-01..06）

- **集成测试加厚**：`tests/integration/test_paper_session_lifecycle.py`、`test_paper_reconcile_killswitch.py`（确定性 mock；start/recover/reconcile/kill-switch）
- **覆盖率门**：`fail_under` 70→**75**；移除 `quantflow/cli/*` omit；CLI `run/status/validate` 测量
- **密钥扫描**：`.github/workflows/gitleaks.yml`（`workflow_dispatch` + 周 cron；全历史；image **v8.24.3** pin；**非** PR 阻断门）
- **文档对齐**：`AGENTS.md` / `CLAUDE.md` 明确 parity=paper↔live only、`docker/docker-compose.yaml`、覆盖率 ≥75
- **依赖锁**：`requirements-lock.txt` 刷新为 **v0.7.x** 表面；`pip-audit --strict` 绿
- **fail-closed 回归**：research GO / promotion fixtures 保持 `promotion_eligible=false`

### L6 研究 GO 导出

- `quantflow/monitoring/research_go_panel.py`：只读密封 `performance_panel.json`
- Prometheus `quantflow_research_go_*` gauges + `MonitoringSink.record_research_go_panel`
- CLI：`python scripts/export_research_go_panel.py`（fail-soft；UTF-8 stdio）
- 指纹未变（`e4d2797070a49bc0`）→ 跳过 full-window multi_symbol_replay 重跑，导出密封值

### Residual 工程修复

- W14 测试/脚本补齐 `execution_path=paper_replay` + fingerprint 戳记
- L1→L2 分层：CVD 下沉 `quantflow/common/cvd.py`；`data/trades_store` 不再 import indicators
- `paper_day_streak` 默认路径晚绑定（monkeypatch 友好）
- gitleaks 禁用 `:latest`

## 破坏性变更

无。研究 GO 导出为只读/可选；gitleaks 非 PR 门；默认 paper/live 行为不变。
