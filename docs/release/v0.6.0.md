# QuantFlow v0.6.0

发布日期：2026-08-10

## 亮点

Option B 定向演进波次 **W14–W21** 合集：晋级纪律、paper 盘口保真、波浪/因子保真、funding 风险门、研究 smoke 路径。**不换引擎**；B0 默认 slip/fill 保持稳定。

### 晋级与成本纪律（W14–W16 / T036）

- `execution_path` 必须为 paper_replay / 事件路径；vectorized-only GO 拒绝
- Paper 可选 BBO fill（默认关）+ BBO age gate
- RD-Agent 仅 validation 旁路，禁止 promote_to_live

### OSS 运维模式吸收

- `PauseReasonSet` 多源暂停
- Ghost position 对账报告
- Preflight 磁盘余量

### 研究保真（W17–W21）

| 波次 | 内容 |
|------|------|
| W17 | 小团队接近行业领先研究 docs（指标/防未来/波浪/盘口） |
| W18 | 真价 pivot + confirmed-only + bar BBO feed + 休眠因子暴露 |
| W19 | Invalidation 接线 + ticker BBO API + session VWAP/OBV slope + save keep-first |
| W20 | BBO poll（默认关）+ bar CVD proxy + Elliott WFO smoke（禁 GO） |
| W21 | Funding risk gate（默认关）+ Elliott paper_replay smoke + trades CVD 脚手架 |

### 指标口径修正

- 不再笼统写「27 registered factors」
- **经典 21 + 扩展列** 由 `IndicatorEngine` 批量计算
- **Wave 6** 为 registry 发现名，需 `wave_count` 专用管道

## 破坏性变更

无默认行为破坏。新增开关全部 **opt-in / 默认 false**。

注意：`FeatureStore.save_features` 同 timestamp 冲突改为 **keep-first**（existing 胜出），避免后写覆盖 PIT 行。
