# QuantFlow v0.1.0 Known Issues

发布日期：2026-06-03

## 已知限制

### 1. 实盘凭证不随包分发

- 描述：`OKX_API_KEY`、`OKX_SECRET`、`OKX_PASSPHRASE` 只能由部署环境提供。
- 影响：未注入环境变量时，`live` 模式不会通过参数校验。
- 处理：发布包保持此限制，不视为缺陷。

### 2. 可选 ML 依赖默认不安装

- 描述：`torch`、`transformers`、`qlib` 等仅属于可选扩展。
- 影响：若启用对应策略链但未安装 extras，相关能力不可用。
- 处理：按需安装 `quantflow[ml]` 或单独安装依赖。

### 3. `vectorbt` 默认未启用

- 描述：`vectorbt` 因其底层依赖在较新 Python 版本上的兼容性问题，未作为默认依赖安装。
- 影响：若研究流程依赖 `vectorbt`，需要由操作者自行补装并验证环境。
- 处理：默认发布路径以当前可验证依赖集合为准。

### 4. 当前交付不包含桌面安装器

- 描述：仓库当前产物为 Python wheel、sdist 和 Docker Compose 部署链路。
- 影响：不支持桌面端双击安装、自动更新和数字签名分发。
- 处理：若后续要做桌面产品化，需要单独增加打包、签名和分发基础设施。
