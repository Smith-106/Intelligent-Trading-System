# v0.10.0 — 异步化、并发写安全与结构工程

发布日期：2026-08-22 · 前一版本：[v0.9.0](v0.9.0.md)

## 主题

本轮为**质量与工程化专项**：三模型共识式审查（deepseek-v4-flash / ox-alpha-free / hy3）驱动两轮 odyssey（REV-008 性能改动对抗审查 + REV-009 结构设计），修复并发数据安全隐患，完成第一批结构拆分。无新交易功能；行为契约经 golden 测试冻结。

## 主要变更

### web station 异步响应
- 全部同步 handler `asyncio.to_thread` 化——下载落盘（zstd 整月重写）期间 kill-switch 控制面保持可达
- `symbol_summary` 单次聚合 SQL 替代每符号双全史扫描（overview 查询约 2x）
- CLI 策略目录懒加载：冷启动 1.90s → 0.59s

### 并发数据安全
- `_save_partitioned`：per-partition 线程锁 + 跨进程 FileLock + tmp 文件原子替换；交错写实测 20/20 行无丢失
- `tag_data_source` 与 save 共用同一锁协议（此前绕锁直写可互删数据）
- 分页硬顶统一 fail-loud（OKX/Bybit K线 + funding/mark/OI）

### 正确性修复
- resolver 补 `-BYBIT` 入链；多候选按后缀优先级决策并告警共存
- overview 空目录/坏分区降级 per-symbol 而非整体 500；NULL data_source 归一 `unknown`（不再出现字面 `"None"` 源键）
- archive 迁移工具候选路径规范化修复（原实现永久 BLOCKED）+ `-BYBIT` 候选
- Bybit OI timeframe 非法值抛带合法值列表的 `DataError`

### 工程化
- 新模块：`cli/render.py`（12 渲染辅助）、`common/netretry.py`（重试/限频公共原语，ISS-REV007-05 解耦）、`data/store.store_scope`
- `indicators.compute_all` 表驱动重构（21 重 if → 声明式 spec 表，371 测试行为等价）
- 安全网：CLI 20 命令注册顺序 golden + validate 命令契约测试
- main.py 2112 → 1898 行
