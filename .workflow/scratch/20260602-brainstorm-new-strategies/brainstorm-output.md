# QuantFlow 新策略方向 — Brainstorm 结果

## 当前策略矩阵

| 策略 | 类型 | 市场状态 | 相关性 |
|------|------|----------|--------|
| Trend Following | 趋势 | 趋势市 | 基线 |
| Mean Reversion | 均值回归 | 震荡市 | 低 |
| Elliott Wave | 波浪 | 全状态 | 中 |

## 候选新策略（按优先级排序）

### 1. 动量因子轮动策略 (Momentum Factor Rotation)
- **核心逻辑**: 多时间框架动量排名 → 横截面动量因子 → 定期轮动调仓
- **指标**: ROC(多周期)、相对强度(RS)、动量加速度
- **互补性**: 与趋势跟踪低相关——趋势跟踪是时间序列动量，这是横截面动量
- **复杂度**: 中
- **适用**: 趋势市（尤其牛市轮动）
- **依据**: Jegadeesh & Titman (1993) 动量效应

### 2. 波动率突破策略 (Volatility Breakout)
- **核心逻辑**: 低波动率收敛 → 波动率扩张突破 → 顺势入场
- **指标**: ATR收缩比、Keltner Channel挤压、BB带宽
- **互补性**: 与现有策略低相关——捕捉波动率状态转换而非价格方向
- **复杂度**: 低
- **适用**: 波动率转换期（盘整→突破）
- **依据**: TTM Squeeze (Carter), BB Squeeze

### 3. 跨交易所套利策略 (Cross-Exchange Arbitrage)
- **核心逻辑**: 同一交易对在不同交易所的价差 → 统计套利
- **指标**: 价差Z-Score、Half-Life、Hedge Ratio (OLS/Kalman)
- **互补性**: 市场中性——不依赖方向，与所有方向性策略负相关
- **复杂度**: 高（需要多交易所数据源 + 低延迟执行）
- **适用**: 全状态
- **依据**: 统计套利文献 (Avellaneda & Lee, 2010)

### 4. 资金费率策略 (Funding Rate Strategy)
- **核心逻辑**: 永续合约资金费率极端值 → 均值回归交易
- **指标**: 资金费率Z-Score、费率趋势、持仓量变化
- **互补性**: Crypto 特有信号，与传统技术指标低相关
- **复杂度**: 低
- **适用**: 震荡市（费率均值回归）
- **依据**: OKX/Binance 资金费率数据

### 5. 机器学习集成策略 (ML Ensemble Alpha)
- **核心逻辑**: XGBoost/LightGBM 多因子集成 → 预测概率 → Meta-Labeling 过滤
- **指标**: 27个因子作为特征 + 滚动训练 + Purged CV
- **互补性**: 与所有规则策略低相关——非线性组合
- **复杂度**: 高（需要 ML pipeline + 防过拟合体系）
- **适用**: 全状态
- **依据**: Advances in Financial ML (de Prado, 2018)

## 推荐实施顺序

| 优先级 | 策略 | 理由 |
|--------|------|------|
| P1 | 波动率突破 | 复杂度低，互补性强，实现快 |
| P2 | 资金费率 | Crypto 特有，简单有效 |
| P3 | 动量轮动 | 需要多品种支持，中等工作量 |
| P4 | ML集成 | 需要完善因子管线，高工作量 |
| P5 | 跨交易所套利 | 架构改动大，优先级最低 |

## 与现有架构的兼容性

所有策略均可通过继承 `StrategyBase` + 添加 YAML 配置实现，无需改动核心架构。
