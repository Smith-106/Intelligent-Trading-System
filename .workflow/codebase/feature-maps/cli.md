Typer + Rich CLI exposing the full workflow download → research → optimize → validate → run, plus benchmark, ai, station, status. Entry point: `quantflow.cli.main:app`.

- `research` — `BacktestEngine` report for a strategy.
- `optimize` — `StrategyOptimizer` (bayesian/cmaes/grid).
- `validate` — anti-overfitting; `--method cpcv|dsr|pbo|wfo|full|gate|lookahead|stress`.
- `run` — `TradingSession` in `paper|sandbox|live` (multi-strategy supported).
- `benchmark` — synthetic performance baseline with optional gates.
- `ai` — `rdagent` (Qlib RD-Agent factor mining, dependency guard).
- `station` — launch QuantFlow Station web UI.
- `status` — system status table.
