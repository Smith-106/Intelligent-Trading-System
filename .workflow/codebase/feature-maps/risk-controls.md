## Description

Multi-layer pre-trade risk gating and position sizing, wired in `TradingSession`: per signal → `RiskEngine.check` → `PositionSizer.size` → `ExecutionEngine.submit_order(PositionRequest)`.

- **`RiskEngine` 7-check short-circuit** (`signal/risk_engine.py`): `position_limit → portfolio_limit → strategy_budget → daily_loss → weekly_loss → drawdown → VaR`; first failure aborts. `_check_var` uses historical CVaR gate.
- **Half-Kelly sizing** (`signal/position_sizer.py`): `PositionSizer` (`kelly_fraction=0.5`) → `size()` returns notional scaled by signal strength + allocation, clamped by `max_position_pct`, optional vol-target cap (opt-in), fee deduction.
- **VaR / CVaR** (`signal/risk_metrics.py`): `value_at_risk` (historical default), `conditional_var` (ES), `bootstrap_cvar` (diagnostic CI), `max_drawdown`, `sharpe/sortino/calmar`.
- **Drawdown circuit breaker**: `_check_drawdown` vs config limit.
- **KillSwitch**: shared fail-closed instance (see FT-005).

Note: there is **no** `ScalingPositionSizer` class in code; `PositionSizer` emits a notional that the session wraps in a `PositionRequest`.
